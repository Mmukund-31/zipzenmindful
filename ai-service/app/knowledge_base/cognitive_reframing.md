title: Cognitive Reframing

Cognitive reframing is a core CBT (Cognitive Behavioral Therapy) skill for challenging distorted or unhelpful thoughts and replacing them with more balanced ones.

Steps:
1. Identify the automatic thought (e.g., "I always mess everything up").
2. Ask evidence-based questions: What's the actual evidence for and against this thought? Would I say this to a friend in the same situation? Is there another way to see this?
3. Name the distortion if there is one — common ones include catastrophizing, all-or-nothing thinking, and mind-reading.
4. Write a more balanced replacement thought (e.g., "I made a mistake this time, but that doesn't erase the times I've done well").

Reframing isn't about forcing false positivity — it's about accuracy. The goal is a thought you actually believe, that is more proportionate to reality than the original automatic thought.
